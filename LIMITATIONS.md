# Limitations

Read this before treating any report as a general ranking of models or harnesses.

## Scope of claims

- **Local open-weight stacks** dominate the coding, prose, and RAG numbers (Ollama, Aider, MLX where noted). Frontier API results appear only when a report explicitly says so.
- Sample sizes are **honest but small** at the cell level (often 2 seeds). Enough to reject weak multi-file paths and gate promotions; not enough to crown permanent winners.
- Studies are labeled **exploratory** unless a confirmatory protocol is named.
- **No unsupervised production graduation** is claimed from these notes alone.

## What is not measured here

- Full SWE-bench or Aider Polyglot as the primary instrument (optional calibration only, not the headline).
- Multi-agent fleet reliability at org scale.
- GxP / regulated system validation from DEV synthetic corpora.
- Exhaustive coverage of all open models.

## Contamination and privacy

Sealed fixtures stay private. This package is methods + sanitized results. If a future public demo split is published, it will be **authored fresh** for public use, not extracted from held-out lab cases.

## Skill-eval maturity

Report 05 documents a real protocol and early instrumentation. It is **not** a large multi-model sealed campaign at the same depth as the coding hard screen. Do not equate the two.

## Preferred language

Prefer: measured, exploratory, not promoted, profile-scoped, DEV routing only.  
Avoid: validated, proven, production-ready agents, overall model quality score.
