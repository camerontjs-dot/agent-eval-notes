    How to read these labels

    These labels are part of the product. They are not footer disclaimers to skip.

    LabelMeaningHow to use it
    ExploratoryUseful for routing and methods; not confirmatoryDo not treat as production proof
    MeasuredNumber from a named suite with n statedPrefer over "validated"
    Not promotedFailed a pre-registered gate or held profile-scopedNot the same as "thrown out"
    DEV routing onlyLocal development defaultNot unsupervised production graduation
    ProvisionalGrades still openTransfer claims that don't need soft grades are still usable
    CeilingSuite no longer discriminates on pass rateExpand cases before ranking
    Honesty rules
    1. State n with every headline metric.
    2. Name the stack (local open-weight vs live frontier) when it matters.
    3. Do not blend coding, prose, RAG, and skill scores into one model quality number.
